Before you start

Three things. Most of you already have one.

  • A laptop running Windows 10/11. Mac and Linux work. Examples are Windows.
  • A personal GitHub account. Free. Sign up at github.com/signup if you don't have one.
  • GitHub Copilot Free on that account. Activated in a couple of clicks. The Setup guide walks you through every step.

No coding experience needed. If you can install software and follow numbered steps, you're set.

How this differs from the GitHub original

The GitHub original is excellent. It is built for software developers working on a Python book app. This version:

  • Uses partner-consultancy scenarios throughout: customer briefings, RFP triage, deal narratives, pipeline analysis.
  • Assumes no coding background. If you can write an email, you can do this.
  • Tunes the MCP examples for tools partner consultants actually live in (M365, GitHub, filesystem).
  • Calls out data boundaries (customer NDA, confidential proposals) explicitly.
  • Stops at the value plateau. Four lessons. No deep dive into building your own agents in v1.

The source course is referenced where it goes deeper than we need to.
